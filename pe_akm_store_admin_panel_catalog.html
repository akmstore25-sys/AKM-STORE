Guía: Cómo publicar esta página permanentemente

El **Modo Admin** guarda los cambios en la memoria local de tu navegador (`localStorage`). Si deseas publicar la página en Internet (ej. en Netlify, Vercel o GitHub Pages) para que tus clientes vean tus productos actualizados directamente, sigue estos sencillos pasos:

1️⃣ Cambiar el Número de WhatsApp en el Código

Abre el archivo index.html en un editor de texto (como Notepad o VS Code) y busca la constante storeWspNumber en la línea ~580 aproximadamente:

let storeWspNumber = '51900000000'; // <-- Reemplaza por tu número con 51

2️⃣ Modificar la lista de productos por defecto

Busca el arreglo de objetos JavaScript denominado initialProducts en el código JavaScript del archivo. Puedes agregar, duplicar o editar productos siguiendo este formato:

{
    id: 'akm-01',
    name: 'Top Rib Daisy Pastel',
    category: 'tops', // 'tops', 'pantalones', 'vestidos', 'outfits', 'accesorios'
    price: 49.90,
    originalPrice: 65.00,
    badge: 'Más Vendido',
    sizes: ['S', 'M', 'L'],
    colorNames: ['Crema', 'Miel'],
    image: 'https://tu-imagen-aqui.jpg',
    description: 'Descripción breve de tu prenda...'
}
